# Wrestling Chronology 0.1.1

- Fixed WCW-specific wording appearing in other companies' episode details and settings.
- Improved Continue Watching on each company's home screen, including episode artwork,
  details, saved time and a progress bar. Progress is saved before returning to the library.
- An unfinished show remains available to continue if the latest selected show failed
  to play or has already been completed. Existing viewing history is preserved.
- Added Jan–Dec shortcuts inside each year. Select a month to jump to its first available
  show without changing the chronological autoplay queue. Empty months are dimmed.
- Fixed focus returning to the old grid position after choosing a month.

Requires Fire OS 6 / Android 7.1 or newer. Install over the existing app to keep history.
This is the same locally signed APK lineage as 0.1.0, with version code 2.
