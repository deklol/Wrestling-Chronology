# Wrestling Chronology 0.1.2

- Added a remote-friendly 4:3 / 16:9 stretch button to the player.
- Added Settings → Picture size (all companies), shared with the player button.
- The picture mode is remembered across companies, episodes and app restarts.
- Stretch widens the 4:3 picture horizontally while preserving its full height,
  including recordings with black side bars inside a wider video frame.

Requires Fire OS 6 / Android 7.1 or newer. Install over the existing app to keep
your viewing history and settings.
